# 废土双工

一个双人合作的 2D 守基地小游戏：两名玩家一起打怪、赚废料、买枪、放置炮塔，守住基地并撑过 10 波攻击。

## 启动

在项目文件夹里打开终端，执行：

```bash
npm install
npm start
```

浏览器打开 <http://localhost:3000>。

## 和朋友一起玩

1. 一个人创建房间。
2. 把顶部的 4 位房间号发给朋友。
3. 朋友打开同一个网址，输入房间号加入。
4. 房主点击“开始防守”。

## 操作

- `WASD` 或方向键：移动。
- 鼠标移动：瞄准。
- 按住鼠标左键或空格：开火。
- 点击商店里的炮塔后，再点击地图：放置炮塔。
- 点击“拆卸炮塔”后点击炮塔，或直接右键点击炮塔：拆卸并返还部分废料。

## 第一版内容

- 双人实时房间。
- 手枪、霰弹枪、突击步枪和火力升级。
- 机枪塔、重炮塔，可放置和拆卸。
- 冲锋怪、巨甲兽、酸液怪。
- 10 波攻击、基地生命值、玩家倒地复活、胜负结算。

## Render 部署

创建 `Web Service`，配置：

```text
Build Command: npm install
Start Command: npm start
```

不要部署成 Static Site。房间数据目前保存在服务器内存里，服务重启后正在进行的房间会消失；单个 Render 实例适合当前这个试玩版本。
