# 抢金币大乱斗

一个适合和朋友一起玩的浏览器多人小游戏。玩家进入同一个房间，在 3 分钟内移动、抢金币，分数最高的人获胜。

## 启动

在这个文件夹里打开终端，执行：

```bash
npm install
npm start
```

然后打开 <http://localhost:3000>。

## 本机测试多人

1. 在第一个页面输入名字，点击“创建房间”。
2. 复制页面顶部的 4 位房间号。
3. 在第二个浏览器窗口打开同一个地址，输入另一个名字和房间号，点击“加入”。
4. 房主点击“开始这一局”。
5. 使用 WASD 或方向键移动抢金币。

## 目录

- `server.js`：房间、玩家移动、金币生成和计分的服务器逻辑。
- `public/index.html`：页面结构。
- `public/style.css`：视觉和响应式布局。
- `public/client.js`：Canvas 游戏画面和键盘操作。
